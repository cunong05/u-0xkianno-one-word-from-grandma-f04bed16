## Why "doohickey"?

It's the classic grandma word for a gadget she can't quite name — warm, a little baffled, and funny in a single word. A doohickey is by definition a bit of kit, a contraption, a mysterious machine thing: exactly what she'd call AI when texting her grandchild about "that doohickey on the phone". Fresh, not the obvious "robot", yet instantly readable by every English speaker.

## How it works

`main.ts` (Node 22, stdlib only, no network) writes exactly one word — `doohickey`, 9 bytes, no trailing newline — to `/output/entry.txt`, after a guard that the word is 1–30 characters and contains no whitespace.

## Run it

```sh
node main.ts
```

Then check the entry:

```sh
cat /output/entry.txt   # doohickey
```
